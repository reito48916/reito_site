# ブログ投稿用のエディタを作った

以前このブログを整理したときに、記事をMarkdownで管理して、GitHub Actionsから自動でGitHub Pagesへ公開できるようにしていた。

<!-- more -->

これだけでも以前よりは楽になったものの、記事を書くたびにMarkdownファイルを作って、画像を配置して、Gitにコミットして…という作業は必要で、大分きつい。

また「ちょっと今日のことを書いておこうかな」くらいのときにPCを開いてこの作業をするのも面倒。

ということで、ブログ投稿用のエディタをスマホからも使えるようにAIにスーパー手伝ってもらいながら自作してみた。

## まずはVueで投稿画面を作る

今回フロント側にはVue 3 + TypeScript + Viteを使った。
自分は普段JavaScriptを書くことはあるものの、Vueをちゃんと使うのは今回がほぼ初めて。

最初はタイトル、日付、本文を入力して、その内容からブログ用のMarkdownを生成さえできればいいということで、シンプルな画面を目指した。

ブログの記事にはFront Matterが必要なので、画面上で入力した内容から、

- 投稿日
- タイトル
- 本文
- `<!-- more -->`

などを自動で組み立てるようにした。

`<!-- more -->`は記事一覧で「続きを読む」に分割するために以前ブログ側へ導入したものだけど、これも毎回自分で書く必要はないので、本文の最初の段落の後ろへ自動挿入するようにした。

## 画像もエディタから挿入できるように

次に対応したのが画像。
画像を選択するとPNGへ変換し、

`docs/images/disposable/YYYY/MM/DD/`

以下へ配置する前提でパスを生成する。

本文中には対応するMarkdownをカーソル位置へ挿入するようにした。

ローカルの簡易プレビューでは、実際にGitHubへ画像を置く前でも確認できるようにBlob URLへ差し替えて表示している。

## 実際のブログと同じ見た目でも確認したい

簡易プレビューだけでも記事の内容は確認できるが、最終的には記事はMkDocs Materialで表示される。となると実際のブログ上でどう見えるのかも公開前に確認したい。

そこでCloudflare WorkersとGitHub APIを使って、プレビュー用ブランチを一時的に作る仕組みも用意した。

エディタから「実サイトプレビュー」を実行すると、

エディタ
↓
Cloudflare Worker
↓
GitHubにプレビュー用ブランチを作成
↓
GitHub ActionsでMkDocsをビルド
↓
プレビュー用URLから確認

という流れで、実際のサイトとほぼ同じ状態を確認できる。

## そして、そのまま公開

プレビューで問題がなければ、同じエディタからそのまま公開できるようにもした。

「公開」を押すとCloudflare Worker経由で記事と画像をGitHubへコミット。

mainブランチが更新されると、以前作っておいたGitHub Actionsが動いてMkDocsをビルドし、GitHub Pagesへ反映される。

公開が完了したら、その記事へのリンクもエディタ上に表示する。

## 最後はエディタ自身もGitHub Pagesへ

ここまでの開発中はローカルでViteを起動してエディタを使っていた。

でも今回やりたかったことの一つは、

**「PCを開かなくてもブログを書けるようにする」**

こと。

そこでエディタ自体も`reito-blog-editor`という別リポジトリにして、GitHub ActionsからGitHub Pagesへデプロイするようにした。

そしてスマホからGitHub Pages上のエディタへアクセスしてちゃんと表示されることを確認。

一応スマホから実サイトプレビューを実行して、そのまま公開まで試してみたところ、こちらも無事成功。

これで、
スマホで記事を書く
↓
画像を入れる
↓
実際のブログ表示をプレビュー
↓
公開
↓
GitHub Actionsが自動デプロイ

というところまで、ブラウザだけで完結するようになった。

## とりあえず完成！

細かいところではまだ改善したい部分もある。

エラー処理や既存記事の扱い、画像ファイル名の衝突対策など、ちゃんと運用するなら考えたいことはいろいろある。

ただ、当初やりたかった

**「スマホからブログを書いて、そのまま公開する」**

というところまでは無事に到達した。

ブログを書くためのツールを作っていたせいでブログを書く時間がなくなる、という本末転倒な状態になりかけていたけど、これで今後はもう少し気軽に更新できる……はず。

ちなみにこの記事も、今回作ったエディタから、文章をAIに考えてもらって投稿している。正直文体が気持ち悪い部分もあるが、疲れたのでとりあえずこれで投稿しておく…。
